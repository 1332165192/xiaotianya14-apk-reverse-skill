# 在手机 App 里使用本技能

> 本技能就是为“手机上的 Agent 环境”写的：不需要 Termux、不需要电脑。下面说明怎么在这个 App 里跑。

## 1. 基本用法

1. 打开对话，直接说任务（例如“给我把这个 APK 的广告清一下”），Agent 会读到 `SKILL.md` 并按流程走。
2. 需要真机操作时，Agent 通过手机操控工具（读屏/点按/输入）执行；需要 root 能力时走 adb 通道（`references/perm-chain.md`）。
3. 产物默认放在手机的下载目录，报告用 `docs/REPORT-TEMPLATE.md`。

## 2. 发布管线（可选）

本技能自带：
- `scripts/make_release.sh`：自检 → 打包 → SHA256 → 解压复检；
- `scripts/publish_github.sh`：建仓/推送/打 tag/建 Release（token 走一次性环境变量）。

配套的手机端插件（输入框上方胶囊）可以把“存令牌 / 发布 GitHub”做成两步点按。

## 3. 远程主机（可选）

手机算力有限时：
- 手机负责：解包、补丁、重打包、真机验证；
- 远程主机负责：Ghidra/IDA 等重工具、大工程反编译；
- 产物通过文件/报告来回传（见 `docs/MCP-INTEGRATION.md`）。

## 4. 机械门（进阶，可选）

宿主 App 的 hooks 机制可以把“必须落台账 / 必须先分诊”变成**工具调用前的硬拦截**（社区有成熟案例）。
本技能默认不装 hooks（会改引擎配置，风险自担）；如果你需要，建议先在测试会话验证，
并在 `settings` 里能随时停用。原则：**只拦截，不代替判断**。
