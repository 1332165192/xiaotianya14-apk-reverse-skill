# 可行性预检报告模板

> 修改类需求（去广告 / 解锁权益 / 改功能 / 改数值）**先填这份报告**，再决定是否补丁。
> 默认一页结论；用户要证据再展开。仅自有/已获授权应用。

## 一句话结论

- 总评：**A 可行 / B 部分可行 / C 仅界面 / D 不可行**
- 广告：**能 / 部分 / 不能**
- VIP / 权益：**能 / 部分 / 不能**
- 能否满足最终目标：**能 / 只能做到 ____ / 不能**

## 证据

| 项 | 发现 | 证据级别 |

| 加固 / 壳 / 完整性 | | observed / measured / inferred |
| 广告 SDK / 广告位 | | |
| 广告配置来源（本地 / 服务端） | | |
| VIP 判定位置（本地 / 服务端） | | |
| 账号 / 设备 / 收据绑定 | | |
| 服务端接口 / 刷新覆盖 | | |
| 其他（Flutter / native / 反调试） | | |

> 证据级别：observed=直接看到；measured=实际运行/抓包测到；inferred=根据代码/行为推断。
> 推断必须标 inferred，不能写成 observed。
